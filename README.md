## 重要!
点击GitHub的Code -> Download ZIP是没有Git的,如果需要Git,请使用命令行:
```bash
git clone https://github.com/T-PageCode/T-CodeSystem.git
```
> 提前是你要安装Git,如果没有安装,请前往git-scm.com来下载,或使用国内镜像站提升下载速度

如果需要在本地启动服务,请输入以下命令(需要安装Python,没有的请到python.org或者国内镜像站下载)
```bash
cd 您的项目文件夹
python -m http.server 端口号
```
最后访问localhost:端口号就行了
